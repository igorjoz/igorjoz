## 🚀 Selected projects

### 🤖 AI & Machine Learning

- **[LarynxAI](https://github.com/LarynxAI)** — A collaborative medical AI project focused on laryngeal pathology classification and AI-assisted image analysis. As part of my engineering thesis, I developed and evaluated a **ConvNeXt-Tiny classifier** for five clinical categories, achieving **85.2% test accuracy and 81.7% macro-F1** on an image-level test set. My research covered transfer learning, data augmentation, handling class imbalance, and model interpretability using Grad-CAM. **[Engineering Thesis (PDF)](https://drive.google.com/file/d/199W4fw4HLqdi14nZgLdSK6FQt8KAbGvq/view?usp=sharing)**

- **[FactorioHRL](https://github.com/FactorioHRL)** — An ongoing academic research project exploring AI agents in Factorio. My work focuses on researching and evaluating **open-weight language models**, while the broader team also investigates hierarchical reinforcement learning (HRL).
